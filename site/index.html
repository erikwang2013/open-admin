open-admin / 开放管理后台

管理后台，
先安全，再开放。

webman v2 + Flutter 全栈后台，认证、RBAC、审计与 18 层纵深防御开箱即用。

2端客户端

一套后台，覆盖从登录到审计的完整链路

后端基于 webman v2 常驻内存进程，管理端使用 Flutter Web 的 PC 布局，移动端提供 HarmonyOS 原生客户端。数据、权限、审计与导出都在同一条链路上。

  • 认证与权限JWT、点击验证码、账号锁定、并发会话限制，以及 method.path 粒度的 RBAC。
  • 数据与审计Snowflake 主键、Hashids 出入参、敏感字段自动加解密、写操作自动落库。
  • 防御与观测31 种攻击检测器、Redis 滑动窗口限流、Prometheus 指标与健康检查。

从零到登录，四步

需要 PHP 8.3+、Composer 2.x 与 MySQL 8.0+。Elasticsearch 7.x 可选，搜索功能需要时再启用。

  1. 安装依赖

    拉取 Composer 依赖，确认 PHP 扩展与数据库连接可用。

  2. 配置环境

    复制环境变量模板，生产环境务必替换 JWT、Hashids 与加密密钥。

  3. 启动服务

    webman 默认监听 8787 端口，启动后保持常驻进程运行。

  4. 完成向导

    访问 /install 填写数据库与管理员信息，自动建表、播种权限并写入 .env。

安装完成后会生成 runtime/install.lock。需要重装时删除该文件即可。

本地启动 
composer install
cp .env.example .env
php start.php start

# 浏览器打开
# http://localhost:8787/install
Docker Compose 部署 
cp .env.docker .env
docker compose up -d

# webman: http://localhost:8787
# Nginx:  http://localhost:8080

API 认证

Bearer Token

Authorization: Bearer <token>

access_token 有效期 2 小时，refresh_token 14 天。401 时调用刷新接口，不在客户端保存明文密钥。

统一响应

code 为 0 即成功

{ "code": 0, "message": "success", "data": {} }

错误码覆盖 400、401、403、404、422、429 与 500。ID 出入参使用 Hashids，不暴露数据库主键。

限流

先看响应头

默认 60 次/分钟/IP/路由，登录接口 10 次/分钟。响应携带 X-RateLimit-Limit、Remaining、Reset，超限时读取 Retry-After。
